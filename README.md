# HobbyPath 🎯

> **Hobiler üzerinden insanları buluşturan, topluluklar oluşturan ve gerçek bağlantılar kuran mobil platform.**

---

## 🧩 Problem

Bir hobiye başladığında ya da hobinle ilgili güvenilir bilgiye ihtiyaç duyduğunda şu anda ne yapıyorsun?

- Instagram'da rastgele birine DM atıyorsun (cevap verir mi bilmiyorsun)
- Dağınık WhatsApp gruplarında kayboluyorsun
- Reddit'te yabancı thread'leri okuyorsun
- Şans eseri doğru kişiyle karşılaşmayı umuyorsun

**HobbyPath bu süreci ortadan kaldırır.**

---

## 💡 Çözüm

Hobisi olanlar ve yeni hobi arayanlar için:
- Hobi bazlı topluluklar
- Seviye uyumlu bağlantılar (Beginner / Intermediate / Advanced)
- Gerçek hayat etkinlikleri
- Güvenilir bilgi alışverişi

---

## 🔄 Uygulama Mantığı

```
DISCOVER → CONNECT → PARTICIPATE → CONTINUE
```

- **Discover** — Yeni hobiler, topluluklar ve etkinlikler keşfet
- **Connect** — Aynı seviyede, aynı hobileri yapan insanlarla bağlantı kur
- **Participate** — Topluluklara katıl, etkinliklere git
- **Continue** — Hobini takip et, ilerlemeni kaydet

## 🛠️ Tech Stack

| Katman | Teknoloji |
|--------|-----------|
| Mobile | Flutter |
| Backend | Java + Spring Boot |
| Database | PostgreSQL |
| Cache | Redis |
| Auth | Spring Security + JWT |
| Real-time | WebSocket |
| AI/Recommendation | Python + FastAPI |
| Container | Docker + Docker Compose |
| API Docs | OpenAPI / Swagger |
